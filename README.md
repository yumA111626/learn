## 協調フィルタリング

「自分と好みが似たユーザーが高く評価した映画」を推薦する、ユーザーベースの協調フィルタリングです。
既存の `requirements.txt` のライブラリで実行できます。外部データの取得は不要です。

```powershell
python collaborative_filtering.py
python collaborative_filtering.py --user Alice --top-n 2 --neighbors 2 --no-show
```

5人×5作品の評価表（1〜5点）を使い、`NaN` を未評価として扱います。
コンソールにユーザー間の類似度とおすすめ映画を表示し、評価表を
`collaborative_filtering_result.png` に保存します。`*` は推薦した映画の予測評価、`?` は未評価です。

コードで追う手順:

1. 共通して評価した映画からPearson相関係数を計算する（共通評価が2件未満、または評価の分散が0なら類似度0）。
2. 未評価の映画ごとに、その映画を評価済みで相関が正のユーザーを、類似度の高い順に最大 `--neighbors` 人選ぶ。
3. 各ユーザーの評価平均からの差を類似度で重み付けし、対象ユーザーの平均に加える。結果は1〜5に収める。
4. 予測評価が高い未評価の映画を最大 `--top-n` 件推薦する。近傍が見つからない映画は候補から外す。

予測式は `対象ユーザーの平均 + Σ(類似度 × (近傍ユーザーの評価 − そのユーザーの平均)) / Σ類似度` です。
平均には、そのユーザーの評価済みの全映画を使います。初期データではAliceにMovie D、Movie Eの順で推薦します。
`make_data()` の評価を変えて、類似度や順位の変化を確認できます。

G検定の学習ポイント:

- 協調フィルタリングは、ユーザーの評価・行動履歴を利用する推薦手法です。このサンプルはメモリベースの一例です。
- アイテムベースでは、似たアイテムを利用して推薦します。映画のジャンルなどの属性を使うコンテンツベースの推薦とも区別しましょう。
- 新しいユーザーやアイテムは履歴が少なく推薦しにくい、コールドスタート問題があります。評価行列の疎さも課題です。
- 少数の共通評価では相関が極端になりやすいため、実務では共通評価数の条件や重みの補正などを検討します。
- このサンプルは仕組みの理解用です。予測性能を測るには評価を学習用・検証用に分け、未使用の評価で検証する必要があります。

## k-means法

k-means法は、似たデータを **k個のクラスタに分ける教師なし学習**です。
正解ラベルは使用せず、各点から所属する重心までの距離の二乗の合計
（クラスタ内平方和）を小さくするように処理します。

## 実行方法

Python 3.10以降を想定しています。ターミナルでこのフォルダへ移動して実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe k_means.py
```

既存のPython環境を使う場合:

```powershell
python -m pip install -r requirements.txt
python k_means.py
```

300個の2次元データを生成し、処理前後のグラフを表示します。
画像は `k_means_result.png` に保存します。図中の赤いXが重心、破線が重心の移動経路です。
グラフの文字は、日本語フォントがなくても表示できるよう英語にしています。

画面表示が不要な場合:

```powershell
python k_means.py --no-show
```

## コードで追う4つの手順

1. データからk個を選び、初期重心にする。
2. 各点を最も近い重心のクラスタに割り当てる。
3. 各クラスタに属する点の平均を計算し、重心を更新する。
4. 重心がほぼ動かなくなるまで2〜3を繰り返す（反復回数にも上限を設ける）。

`k_means.py` では学習用にこの処理をNumPyで実装しています。
`labels` は所属クラスタの番号、`centers` は重心の座標です。
番号そのものに大小や意味はありません。

## 試してみよう

```powershell
python k_means.py --k 2 --output k2.png
python k_means.py --k 4 --output k4.png
python k_means.py --seed 10 --output seed10.png
```

- **kを変える**: 同じデータがどのように分割されるか比較してください。kは事前に指定します。
- **seedを変える**: 初期重心と移動経路を比較してください。データ自体は固定されています。最終結果が同じになる場合もあります。
- **データを変える**: `make_data()` の `scale=0.8` を `1.8` に変更すると、点の集まりが重なりやすくなります。

## G検定の学習ポイント

- k-meansはクラスタリングであり、正解ラベルを使う分類とは異なります。
- 初期重心によって結果が変わり、局所的な解に落ち着く場合があります。実務では複数回の初期化などを用います。
- 距離を使うので、特徴量の単位や尺度が大きく異なる場合には標準化などを検討します。
- 球状にまとまったクラスタが得意で、複雑な形状や外れ値の影響には注意が必要です。
- kを増やすと最適なクラスタ内平方和は小さくなるため、この値だけで最適なkは決まりません。エルボー法などで検討します。
- このサンプルは仕組みの理解用です。実務ではscikit-learnの `KMeans` なども利用できます。
