# k-means法 ハンズオン

k-means法は、似たデータを **k個のクラスタに分ける教師なし学習**です。
正解ラベルは使用せず、各点から所属する重心までの距離の二乗の合計
（クラスタ内平方和）を小さくするように処理します。

## 実行方法

Python 3.10以降を想定しています。ターミナルでこのフォルダへ移動して実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe k_means.py
```

既存のPython環境を使う場合:

```powershell
python -m pip install -r requirements.txt
python k_means.py
```

300個の2次元データを生成し、処理前後のグラフを表示します。
画像は `k_means_result.png` に保存します。図中の赤いXが重心、破線が重心の移動経路です。
グラフの文字は、日本語フォントがなくても表示できるよう英語にしています。

画面表示が不要な場合:

```powershell
python k_means.py --no-show
```

## コードで追う4つの手順

1. データからk個を選び、初期重心にする。
2. 各点を最も近い重心のクラスタに割り当てる。
3. 各クラスタに属する点の平均を計算し、重心を更新する。
4. 重心がほぼ動かなくなるまで2〜3を繰り返す（反復回数にも上限を設ける）。

`k_means.py` では学習用にこの処理をNumPyで実装しています。
`labels` は所属クラスタの番号、`centers` は重心の座標です。
番号そのものに大小や意味はありません。

## 試してみよう

```powershell
python k_means.py --k 2 --output k2.png
python k_means.py --k 4 --output k4.png
python k_means.py --seed 10 --output seed10.png
```

- **kを変える**: 同じデータがどのように分割されるか比較してください。kは事前に指定します。
- **seedを変える**: 初期重心と移動経路を比較してください。データ自体は固定されています。最終結果が同じになる場合もあります。
- **データを変える**: `make_data()` の `scale=0.8` を `1.8` に変更すると、点の集まりが重なりやすくなります。

## G検定の学習ポイント

- k-meansはクラスタリングであり、正解ラベルを使う分類とは異なります。
- 初期重心によって結果が変わり、局所的な解に落ち着く場合があります。実務では複数回の初期化などを用います。
- 距離を使うので、特徴量の単位や尺度が大きく異なる場合には標準化などを検討します。
- 球状にまとまったクラスタが得意で、複雑な形状や外れ値の影響には注意が必要です。
- kを増やすと最適なクラスタ内平方和は小さくなるため、この値だけで最適なkは決まりません。エルボー法などで検討します。
- このサンプルは仕組みの理解用です。実務ではscikit-learnの `KMeans` なども利用できます。
